## 4. Technical decisions added since 9/18 / 新增技术约定

- **Three reading arrays:** `baseReadings` (ABG; `be` = ABE), `labReadings` (chem/CBC/coag/inflammation), `vitalReadings` (oral BP/HR/pressors; approximate `h`).
- **Hero pill:** `latestNonBloodGasReport` wins when newer than last arterial.
- **Hires ABG:** often 3520×3772, filename contains `__hires__`. Prefer the table on the hires sheet over phone-crop OCR.
- **Same-clock replace:** keep the old file; set `preferred: false` and `superseded_by` (or a SUPERSEDED note). Do not delete.
- **Syntax check:** extract the dashboard `<script>` into `/tmp/medidash-check.js` and run `node --check` before commit.
- **OCR traps:** videoReview/computerUse often garble Chinese (e.g. PCT 36.9 → 96.39). Trust the code + hires table. Infinite PIL slice on a 1080×15826 ABG filled disk — use **finite** slices only.
- **Do not invent:** weight; dopamine mg/h; early pressor mL when family only said “high / about half”.
- **Push path:** MediDash `main` only. Do not print the PAT.
